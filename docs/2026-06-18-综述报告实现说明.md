## 数据流

```
用户请求（含 scope + timeRange）
  → openclaw-napm-summary / SummaryService.run()
    ├── plan(scope, timeRange) → 查询计划（按 scope 选择 API）
    ├── execute(plan) → 并行调用 NAPM API（Promise.allSettled）
    │   ├── alertsSummary + alertsSummaryTimeLine
    │   ├── timeValues（流量趋势）
    │   ├── topValues（TopN / 钻取）
    │   └── applianceInfo
    └── aggregate(rawData, scope) → 标准 summary 数据块
  → SummaryReportDataService.buildReportData()
    → reportData（schema + reportType + templateId + scope + summary）
  → ReportInputContractService.normalizeReportInput()
  → ReportTemplateService.renderDocx()
    → SummaryFixedTemplateService.renderDocx()
      ├── filterSectionsByScope（按 scope.type 过滤章节）
      ├── preRenderCharts（ECharts SSR，同步过滤图表槽位）
      ├── renderSection × N（heading / table / narrative / chartSlot）
      └── Packer.toBuffer() → .docx 文件
  → ReportStorageService（scope 驱动文件名）→ 落盘
```

```bash

  --payload '{"scope":{"type":"global","label":"全局"},"timeRange":{"start":1780882620,"end":1780969020}}'

# 239web 业务综述（最近7天）
node skills/openclaw-napm-summary/scripts/run_summary.js \
  --queryJson '{"scope":{"type":"webApplication","label":"业务","target":{"groupType":"WebApplication","groupArgument":"239web","groupLabel":"239web"}},"timeRange":{"start":1780272000,"end":1780876800}}'

# 从文件读取
```
