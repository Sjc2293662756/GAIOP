## 1. 概述

本项目（观枢 GAIOP / NAPM Semantic Gateway）是一个基于 OpenClaw 的 NAPM 智能运维助手平台，包含 **9 个 Skill**，通过 **7 个 OpenClaw 工具契约** 对外暴露能力。

项目中可自定义的参数分布在四个层级：

| 层级 | 载体 | 修改方式 | 生效方式 |
|------|------|----------|----------|
| **环境变量** | `.env` 文件 | 编辑文件 | 重启服务 |
| **配置文件** | `config/*.json`、`config/*.yml` | 编辑文件 | 重启服务 / 技能重载 |
| **Skill 输入** | 运行时 JSON payload | 由上游 OpenClaw/用户传参 | 即时生效 |
| **硬编码常量** | `services/*.js` | 修改源码 | 重新部署 |

## 3. 环境变量层

> **文件位置**: `.env`（实际生效）、`.env.example`（模板）  
> **修改方式**: 编辑 `.env` 文件  
> **生效方式**: 重启 OpenClaw Gateway

### 3.1 NAPM API 连接与认证

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `NETINSIDE_HOST` | *(空)* | `string` | NAPM WebService 根 URL。<br>格式: `https://<host>/webservice/NetInside` |
| `NETINSIDE_USERNAME` | *(空)* | `string` | NAPM API 认证用户名 |
| `NETINSIDE_PASSWORD` | *(空)* | `string` | NAPM API 认证密码 |
| `NETINSIDE_TLS_INSECURE` | `false` | `boolean` | 设为 `true` 跳过自签名/无效 HTTPS 证书验证 |

> ⚠️ **安全提示**: `.env` 文件不得提交到 Git。`.env.example` 中仅保留空值占位。

### 3.2 服务运行配置

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `PORT` | `8083` | `number` | 网关 HTTP 服务端口 |
| `NODE_ENV` | `development` | `string` | 运行环境标识：`development` / `production` |

### 3.3 日志与调试

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `LOG_LEVEL` | `info` | `string` | 日志级别：`debug` / `info` / `warn` / `error` |
| `LOG_FILE` | `logs/app.log` | `string` | 日志文件路径（相对于项目根目录） |
| `SHOW_UPSTREAM_API_IN_REPLY` | `false` | `boolean` | 设为 `true` 时，回复中会暴露 NAPM API 调试 URL<br>⚠️ 生产环境必须为 `false` |

### 3.4 网关与 Skill 开关

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `DISABLE_GATEWAY_TEMPLATES` | `false` | `boolean` | 禁用网关模板渲染 |
| `SKILL_DISABLE_GATEWAY_BRIDGE` | `false` | `boolean` | 设为 `true` 时不调用旧版 `/api/gateway/tools/napm.skill.query` |
| `SKILL_UNDERSTANDING_ONLY` | `false` | `boolean` | 设为 `true` 时仅做意图理解，跳过真实查询执行 |
| `SKILL_ENABLE_GATEWAY_SKILL_BRIDGE` | `true` | `boolean` | 启用 Skill → Gateway 桥接执行 |
| `SKILL_FORWARD_DISPLAY_TEXT` | `false` | `boolean` | 设为 `true` 时透传 displayText/replyText；<br>`false` 时由 OpenClaw 从 narrationInput 自行叙述 |
| `NAPM_RESOLUTION_BOUNDARY_MODE` | `strict` | `string` | 查询边界模式。当前固定为 `strict`：必须在执行前构造完整 resolvedQuery |
| `GATEWAY_QUERY_ONLY_MODE` | `true` | `boolean` | 网关仅查询模式（推荐保持 `true`） |
| `GATEWAY_ENFORCE_UPSTREAM_EXECUTION` | `true` | `boolean` | 强制网关只接受上游已执行的契约（assistantDecision + resolvedQuerySeed） |
| `GATEWAY_UNDERSTANDING_ONLY` | `false` | `boolean` | 网关理解模式开关 |
| `GATEWAY_ALLOW_INTENT_TRACE_IN_REPLY` | `false` | `boolean` | 是否允许在 displayText 中追加意图追踪文本（含 mode/confidence） |
| `GATEWAY_FORWARD_DISPLAY_TEXT` | `false` | `boolean` | 网关层是否透传 displayText 到上层 |

### 3.8 数据包分析专属

#### 3.8.1 下载控制

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `PACKET_MAX_TIME_RANGE_SECONDS` | `3600` | `number` | 单次数据包下载允许的最大时间窗口（秒）。<br>超过此值会提示缩小范围 |
| `PACKET_DOWNLOAD_DIR` | `$HOME/.openclaw/artifacts/openclaw-napm-packet-analysis` | `string` | 下载的 pcap 文件存放目录 |
| `PACKET_RETENTION_HOURS` | `24` | `number` | 下载文件保留时长（小时）。超期文件会在下次下载任务启动时自动清理 |
| `PACKET_KEEP_FILES` | `true` | `boolean` | 分析完成后是否保留原始 pcap 文件供短期查看/跟进分析 |
| `PACKET_AUTH_QUERY_PARAMS` | `true` | `boolean` | 数据包 URL 中是否附加 `UserName`/`Password` 查询参数（NetInside 要求） |
| `PACKET_HTTP_TIMEOUT_MS` | `60000` | `number` | 数据包下载 HTTP 请求超时（毫秒） |
| `PACKET_MAX_BYTES` | `524288000` | `number` | 单次下载最大字节数限制。<br>默认 500MB（`500 × 1024 × 1024`） |

#### 3.8.2 预览风险阈值

> 以下阈值用于 `packetsPreview` 阶段的风险评估，决定是否需要用户确认后才能下载。

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `PACKET_PREVIEW_WARN_BYTES` | `209715200` | `number` | 预览阶段警告阈值（字节）。<br>默认 200MB，超过触发 `CONFIRM_DOWNLOAD` |
| `PACKET_PREVIEW_BLOCK_BYTES` | `1073741824` | `number` | 预览阶段阻止阈值（字节）。<br>默认 1GB，超过触发 `SUGGEST_NARROW_TIME_RANGE` |
| `PACKET_PREVIEW_WARN_PACKETS` | `200000` | `number` | 预览包数警告阈值 |
| `PACKET_PREVIEW_BLOCK_PACKETS` | `1000000` | `number` | 预览包数阻止阈值 |
| `PACKET_PREVIEW_BLOCK_UNKNOWN` | `true` | `boolean` | 当数据包大小未知时是否阻止自动下载 |
| `PACKET_PREVIEW_BLOCK_MEDIUM` | `false` | `boolean` | 中等风险时是否也阻止（默认仅阻止高风险） |
| `PACKET_PREVIEW_CONFIRM_DOWNLOAD` | `false` | `boolean` | 是否所有下载都需要用户确认 |

#### 3.8.3 存储治理

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `PACKET_STORAGE_WARN_PERCENT` | `75` | `number` | 磁盘使用警告百分比 |
| `PACKET_STORAGE_CLEAN_PERCENT` | `80` | `number` | 触发自动清理的磁盘使用百分比。<br>达到后按下载时间从旧到新清理 |
| `PACKET_STORAGE_TARGET_PERCENT` | `70` | `number` | 清理目标百分比（清理到此水位停止） |

#### 3.8.4 工具路径

| 变量名 | 默认值 | 类型 | 说明 |
|--------|--------|------|------|
| `PACKET_TSHARK_BIN` | `tshark` | `string` | tshark 可执行文件路径或命令名 |
| `PACKET_CAPINFOS_BIN` | `capinfos` | `string` | capinfos 可执行文件路径或命令名 |
| `SHOW_PACKET_FULL_URLS` | `false` | `boolean` | 调试用：是否在返回中展示完整数据包 URL |

## 4. 配置文件层

> **文件位置**: `config/` 目录  
> **修改方式**: 编辑 JSON/YML 文件

### 4.1 巡检报告规则

**文件**: [`config/inspection-report-rules.v1.json`](../config/inspection-report-rules.v1.json)

```json
{
  "schema": "openclaw_napm_inspection_rules.v1",
  "timezone": "Asia/Shanghai",
  "thresholds": {
    "minOneMinuteRetentionDays": 7,
    "packetDropsWarningGreaterThan": 0,
    "packetDupRateWarningGreaterThan": null,
    "diskUsageWarningPercent": 85,
    "cpuUsageWarningPercent": 85,
    "dataLagWarningMinutes": 30,
    "defaultBusinessGroupCount": 4,
    "minPacketStorageDays": null,
    "trafficSpikeRatio": 3,
    "trafficZeroSegmentWarningGreaterThan": 0,
    "businessSlowRatioWarningGreaterThan": 0,
    "businessSlowCountWarningGreaterThan": 0,
    "businessHttp400WarningGreaterThan": 0,
    "businessHttp500WarningGreaterThan": 0
  }
}
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `timezone` | `string` | `"Asia/Shanghai"` | 巡检报告使用的时区 |
| `minOneMinuteRetentionDays` | `number` | `7` | 1 分钟粒度数据最少保留天数 |
| `packetDropsWarningGreaterThan` | `number` | `0` | 丢包数告警阈值（超过触发告警） |
| `packetDupRateWarningGreaterThan` | `number\|null` | `null` | 重复包率告警阈值（null=不检查） |
| `diskUsageWarningPercent` | `number` | `85` | 磁盘使用率告警百分比 |
| `cpuUsageWarningPercent` | `number` | `85` | CPU 使用率告警百分比 |
| `dataLagWarningMinutes` | `number` | `30` | 数据延迟告警分钟数 |
| `defaultBusinessGroupCount` | `number` | `4` | 巡检中默认展示的业务组数量 |
| `minPacketStorageDays` | `number\|null` | `null` | 数据包最少存储天数（null=不检查） |
| `trafficSpikeRatio` | `number` | `3` | 流量突增倍数阈值（当前值÷均值 > 3 视为突增） |
| `trafficZeroSegmentWarningGreaterThan` | `number` | `0` | 零流量段告警阈值 |
| `businessSlowRatioWarningGreaterThan` | `number` | `0` | 业务慢页面比例告警阈值 |
| `businessSlowCountWarningGreaterThan` | `number` | `0` | 业务慢页面数量告警阈值 |
| `businessHttp400WarningGreaterThan` | `number` | `0` | HTTP 400 告警阈值 |
| `businessHttp500WarningGreaterThan` | `number` | `0` | HTTP 500 告警阈值 |

> **自定义场景**: 不同客户的 SLA 标准不同，可按需调整。例如对金融服务可降低 `cpuUsageWarningPercent` 到 70%、提高 `trafficSpikeRatio` 到 5。

### 4.3 对象本体定义

**文件**: [`config/object-ontology.v1.json`](../config/object-ontology.v1.json)

定义 NAPM 中每种对象类型的中文/英文别名、API 类型映射、编目角色等。

每个对象的可自定义字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `cnAliases` | 中文别名列表 | `["业务", "业务系统", "Web应用"]` |
| `enAliases` | 英文别名列表 | `["WebApplication", "webapp"]` |
| `applicationTypeFilter` | API 类型过滤 | `[3]` |
| `applicationCatalogRole` | 编目角色名 | `"web_business"` |
| `inventoryProvider` | 清单数据来源 | `"applications"` / `"businessGroups"` / `"groupArguments"` |
| `executionGroupType` | 执行时使用的分组类型名 | `"WebApplication"` |
| `description` | 对象说明 | — |

当前定义的 9 类对象：

| objectType | 中文主名 | API 来源 |
|------------|----------|----------|
| `BusinessGroup` | 业务组/工作组 | `businessGroups` |
| `WebApplication` | 业务/业务系统/Web 应用 | `applications` (Type=3) |
| `DefinedApp` | 已定义应用/服务器应用 | `applications` (Type=2) |
| `CompositeApplication` | 自动识别应用/复合应用 | `applications` (Type=4) |
| `BuiltinApplication` | 内置应用/内置端口应用 | `applications` (Type=1) |
| `OtherApp` | 未知应用/未知端口 | `groupArguments` |
| `PageFamily` | 页面族 | `groupArguments` |
| `User` | 用户 | `groupArguments` |
| `ClientBusinessGroup` | 客户端业务组/初始组 | `groupArguments` |

> **自定义场景**: 不同客户使用不同中文术语（如"工作组" vs "业务分组"），修改 `cnAliases` 即可适配。

### 4.4 指标配置

**文件**: [`config/metrics-config.yml`](../config/metrics-config.yml)

定义全部 107 个 NAPM 指标的代码、描述和单位映射。格式：

```yaml
metrics:
  - code: CSTI
    description: 连接建立时间(TCP服务器)
    unit: t
  - code: PGSLPCTS
    description: 慢页面百分比（客户端）
    unit: '%'
  # ... 共 107 条
```

| 字段 | 说明 |
|------|------|
| `code` | 指标代码（与 NAPM API 一致） |
| `description` | 中文描述 |
| `unit` | 单位：`t`(时间)、`%`、`#`、`data`(数据量)、`个/秒`、`个/分钟`、`千bits/秒` |

> **自定义场景**: NAPM 新增指标时在此追加；指标中文名可根据客户习惯修改。

### 4.5 静态分组下钻树

**文件**: [`config/groups-tree.static.json`](../config/groups-tree.static.json)

定义 NAPM 所有对象类型的层级关系和下钻路径。结构为嵌套树，每个节点包含：

| 字段 | 说明 |
|------|------|
| `argumentType` | 参数类型 ID |
| `canQuery` | 是否可查询 |
| `key` | 对象键名（如 `IPAddress`、`WebApplication`） |
| `label` | 显示标签（如 `IP地址`、`WEB应用`） |
| `type` | 类型编号 |
| `children` | 下级可钻取对象 |

> **自定义场景**: NAPM 版本升级导致下钻层级变化时，替换此文件即可。

### 4.6 查询解析规范

**文件**: [`config/napm-resolution-spec.v1.json`](../config/napm-resolution-spec.v1.json)

定义 8 种服务的查询契约。每种服务的可自定义部分：

```json
{
  "serviceName": {
    "category": "data_query | metadata_query | analysis_query | ...",
    "semanticHints": ["触发词1", "触发词2", ...],
    "required": ["必填字段1", ...],
    "optional": ["可选字段1", ...],
    "queryModes": ["topn | average | timeseries | ..."]
  }
}
```

当前定义的 8 种服务：

| 服务名 | 类别 | 说明 |
|--------|------|------|
| `topValues` | data_query | TopN 排行查询 |
| `averageValues` | data_query | 均值查询 |
| `timeValues` | data_query | 时间序列/趋势查询 |
| `overview` | analysis_query | 综合分析/概览 |
| `groups` | metadata_query | 分组/对象清单 |
| `metrics` | metadata_query | 指标清单 |
| `drilldownCatalog` | metadata_query | 下钻目录 |
| `topValues_multi_protocol` | synthetic_query | 多协议排行（TCP/UDP） |
| `security_refusal` | decision_only | 安全拒绝 |

> **自定义场景**: 新增查询服务、调整语义触发词、改变必填/可选字段列表。

## 5. 各 Skill 运行时输入参数

> **生效方式**: 调用时传参，即时生效，无需重启

### 5.1 openclaw-napm-query — NAPM 查询

**核心契约**: 必须传入完整 `resolvedQuery`，参数说明：

#### 通用字段

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `service` | `string` | ✅ | 服务类型（见上表） |
| `queryModeKey` | `string` | ✅ | 查询模式 |
| `start` | `number` | ✅(数据) | 开始时间（Unix 秒） |
| `end` | `number` | ✅(数据) | 结束时间（Unix 秒） |
| `metrics` | `string[]` | ✅(数据) | 指标代码列表 |
| `format` | `string` | 可选 | 输出格式，默认 `json` |

#### topValues 专属

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `topMetric` | `string` | ✅ | 排序主指标 |
| `topCount` | `number` | 可选 | TopN 数量 |
| `groups` | `object[]` | 可选 | 查询对象分组 |
| `filters` | `object` | 可选 | 过滤条件 |

#### timeValues 专属

- Step 3: `PageTime`, `ServBusyTime`, `NetBusyTime`，阈值 60%

**C/S 应用慢步骤指标**:
- Step 1: `TPIO`, `UEIO`, `RTTI`, `RTTO`, `PLI`, `PLO`, `RFCI`, `RFCO`
- Step 2: `UEIO`, `TRTO`, `PTTO`, `RDTO`
- Step 3: Top 客户端 IP
