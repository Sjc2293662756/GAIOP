## 二、改造方案

### 2.1 软件版本：设为固定值 "5.0"，预留手动修改入口

**方案**：利用已有的 `options.softwareVersion` 覆盖机制，设默认值为 `"5.0"`，不再从 NAPM 查询结果中取。

#### 改动点 1：`InspectionFieldMapperService.js` line 175

**当前：**
```js
const softwareVersion = asText(options.softwareVersion || parseSysVersion(aboutHtml) || source.mktVersion || source.uiVersion);
```

**改为：**
```js
const DEFAULT_SOFTWARE_VERSION = '5.0';   // ← 集中常量，方便后期手动修改
const softwareVersion = asText(options.softwareVersion || DEFAULT_SOFTWARE_VERSION);
```

> 说明：`options.softwareVersion` 优先级最高，如果调用方传了就用调用方的；否则统一用 `"5.0"`。不再走 `parseSysVersion(aboutHtml)` 的查询链路。

#### 改动点 2：`SummaryService.js` line 1339

**当前：**
```js
softwareVersion: raw.uiVersion || raw.mktVersion || raw.softwareVersion || raw.version || '',
```

**改为：**
```js
softwareVersion: '5.0',
```

> 同上，综述的设备信息不再从 NAPM 查询字段中取值，统一用 `"5.0"`。

#### 变动汇总

| 文件 | 改动 | 影响 |
|------|------|------|
| `InspectionFieldMapperService.js:175` | 取值优先级改为 `options.softwareVersion \|\| '5.0'` | 巡检报告 |
| `SummaryService.js:1339` | 硬编码为 `'5.0'` | 综述报告 |

### 2.2 序列号：查询 + 前缀替换 `ARXVXA-` → `NAPM-`

**方案**：保留 NAPM 查询逻辑（从 `applianceInfo.properties.SerialNumber` 取值），但修改 `formatSerialNumber()` 的转换规则：

- 原：`ARXVXA-D071C7FA987A4606` → `NetInside NAPM 4.0-D071C7FA987A4606`
- 新：`ARXVXA-D071C7FA987A4606` → `NAPM-D071C7FA987A4606`

#### 改动点 1：`InspectionFieldMapperService.js` — `formatSerialNumber()` line 121-128

**当前：**
```js
function formatSerialNumber(value = '') {
  const text = asText(value);
  if (!text) return '';
  if (/^(ARXVXA|ARX3800)-/i.test(text)) {
    return text.replace(/^(ARXVXA|ARX3800)/i, 'NetInside NAPM 4.0');
  }
  return text;
}
```

**改为：**
```js
function formatSerialNumber(value = '') {
  const text = asText(value);
  if (!text) return '';
  // 通用前缀替换：将原始前缀（如 ARXVXA、ARX3800）统一替换为 NAPM
  return text.replace(/^[A-Z0-9]+-/i, 'NAPM-');
}
```

> 用通用正则 `/^[A-Z0-9]+-/i` 匹配任意大写字母+数字前缀（含连字符），统一替换为 `NAPM-`。
> 如果序列号没有 `XXXXXX-` 格式的前缀，保持原样不变。

**效果示例：**

| 原始值 | 转换后 |
|--------|--------|
| `ARXVXA-D071C7FA987A4606` | `NAPM-D071C7FA987A4606` |
| `ARX3800-ABCD1234EFGH5678` | `NAPM-ABCD1234EFGH5678` |
| `NO_PREFIX_SERIAL` | `NO_PREFIX_SERIAL`（无连字符前缀，不变） |

#### 改动点 2：`SummaryService.js` — `_normalizeDeviceInfo()` line 1340

**当前：**
```js
serialNumber: raw.serialNumber || raw.sn || '',
```

**改为：**
```js
serialNumber: this._formatSerialNumber(raw.serialNumber || raw.sn || ''),
```

并在 `SummaryService` 类上新增同名方法（与 inspection 保持一致）：
```js
_formatSerialNumber(value = '') {
  const text = String(value || '').trim();
  if (!text) return '';
  return text.replace(/^[A-Z0-9]+-/i, 'NAPM-');
}
```

> 或者将 `formatSerialNumber` 抽取为共享工具函数，两个 Service 都引用同一函数，避免重复定义。

#### 变动汇总

| 文件 | 改动 | 影响 |
|------|------|------|
| `InspectionFieldMapperService.js:121-128` | `formatSerialNumber()` 正则通用化 | 巡检报告 |
| `SummaryService.js:1340` | 序列号也经过 `_formatSerialNumber()` 转换 | 综述报告 |
