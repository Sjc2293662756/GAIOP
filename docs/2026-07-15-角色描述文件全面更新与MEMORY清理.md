# 角色描述文件全面更新与 MEMORY 清理

日期：2026-07-15

## 背景

项目经历了多轮功能更新（fault-diagnosis 独立为第 9 个 Skill、bs_page_perf 页面性能分析流程、CS 应用故障分析全链路、流程类型自动解析等），但 8 个角色描述文件未同步。同时 MEMORY.md 长期积累了大量开发实施记录，与 AI 日常运维决策无关，需要清理。

## 关键发现

- **Skill 实际有 9 个**：PROJECT.md 写的是 8 个，漏了 `openclaw-napm-fault-diagnosis`
