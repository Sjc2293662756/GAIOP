# Skill直查直叙述收口说明

## 这次改了什么

- `openclaw-napm-query` 负责直查，但不再强行把结果写死成固定文案模板。
- 默认改为让 OpenClaw 基于结构化语义结果自行组织中文叙述。
- `displayText` 不再自动前推，只有显式开启 `SKILL_FORWARD_DISPLAY_TEXT=true` 时才走透传文案。

## 现在的效果

- 用户问“系统中都有哪些 web 应用”时，Skill 会自己查。
- 最终怎么讲，由 OpenClaw 根据 `narrationInput`、`summary`、`structuredRows` 按语义自由组织。

## 说明

- 网关仍可保留为执行入口，但不再承担结果叙述主责任。
- 这次主要收口在 Skill 侧，目标是“直查 + 结构化返回”，不是“本地规则模板化叙述”。
