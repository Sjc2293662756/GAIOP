# Skill直查不走网关说明

## 目标

当前链路调整为：

- 企微插件只调用本地 `openclaw-napm-query` skill 执行器
- skill 自己完成查询并返回结构化结果
- 不再回落到旧 skill.query 网关接口

## 本次处理

企微插件中的 `requestNapmSkillQuery()` 已改为：

1. 优先执行本地 `run_napm_query.js`
2. 若本地 skill 执行失败，直接返回 `LOCAL_NAPM_SKILL_EXECUTOR_FAILED`
3. 不再 fetch 本地网关接口作为兜底

## 说明

- `run_napm_query.js` 当前默认就是“不走网关桥接”的方向
- 真正还在偷偷走网关的是企微插件的 fallback
- 本次已把这条 fallback 移除
