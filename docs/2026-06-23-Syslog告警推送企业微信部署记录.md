## 3. 部署步骤记录

### 3.1 配置 rsyslog

```bash
# 安装 rsyslog
sudo apt install -y rsyslog

# 创建日志目录
sudo install -d -o syslog -g adm -m 0755 /var/log/netinside
sudo touch /var/log/netinside/syslog.log
sudo chown syslog:adm /var/log/netinside/syslog.log
sudo chmod 0640 /var/log/netinside/syslog.log

# 配置 UDP 514 接收
sudo tee /etc/rsyslog.d/10-netinside.conf >/dev/null <<'EOF'
module(load="imudp")

template(name="NetinsideSyslogRaw" type="string"
         string="%timegenerated:::date-rfc3339% from=%fromhost-ip% host=%HOSTNAME% facility=%syslogfacility-text% severity=%syslogseverity-text% tag=%syslogtag%%msg%\n")

ruleset(name="netinside_udp514") {
    action(type="omfile" file="/var/log/netinside/syslog.log" template="NetinsideSyslogRaw")
    stop
}

input(type="imudp" port="514" ruleset="netinside_udp514")
EOF

sudo systemctl restart rsyslog
sudo systemctl enable rsyslog
```

### 3.5 遇到的问题与修复

| 问题 | 原因 | 修复 |
|---|---|---|
| `Failed at step CHDIR` | `ProtectHome=yes` 阻止了 /home 访问 | 改为 `ProtectHome=read-only` |
| `invalid webhook url` (93000) | 用户初始提供的 bot id 是智能机器人凭证，非群机器人 Webhook | 重新在群里添加群机器人获取正确 Webhook URL |
| `self-signed certificate` | AlertEnrichment TLS 跳过逻辑写反 | `rejectUnauthorized: !(tlsInsecure === true)` |
| systemd Description 中文乱码 | plink SSH 编码问题导致中文损坏 | 使用 ASCII-only Description |
| **告警卡片中文乱码** | NAPM Syslog 输出 GBK 编码，Node.js 按 UTF-8 解码 | 添加 `iconv-lite` 依赖，UTF-8 含 `�` 时自动回退 GBK |
| **严重级别显示 `notice` 而非业务级别** | 取值顺序错误：先取了 syslog 协议层 severity | 改为 `alert.alertSeverity \|\| alert.severity`，业务级别优先 |
| **NAPM API 返回 400** | ① AlertEnrichment 用 POST JSON 调 NAPM API，但 NAPM API 是 GET + URL query string 方式<br>② 时间戳未对齐分钟（NAPM 要求 60 的整数倍） | ① 改为 `?UserName=xxx&Password=xxx&type=alertsDetail&eventids=xxx&...`<br>② `Math.floor(ts / 60) * 60` 对齐分钟 |
| **真实 NAPM Syslog 解析不到** | NAPM 实际输出的时间戳含微秒 `13:29:53.112514+08:00`，正则只匹配了秒级 `13:29:53+08:00` | 正则增加可选微秒：`(?:\\.\\d+)?` |
| **去重配置 `windowSeconds: 0` 不生效** | `0 \|\| 300` = `300`（JS `\|\|` 把 0 当 falsy） | 改为 `??`（nullish coalescing）：`?? 300`，仅 undefined/null 时用默认值 |

## 6. 配置项说明

配置文件：`config/watcher.config.json`

| 配置路径 | 值 | 说明 |
|---|---|---|
| `syslog.path` | `/var/log/netinside/syslog.log` | Syslog 日志文件路径 |
| `napm.host` 或 `napm.baseUrl` | `https://101.254.114.238/webservice/NetInside` | NAPM API 地址（支持 `host`/`baseUrl`/纯IP 多种写法） |
| `napm.username` | `GAIOP` | NAPM 用户名 |
| `napm.password` | `GAIOP123` | NAPM 密码 |
| `napm.tlsInsecure` | `true` | 跳过自签证书验证 |
| `napm.requestTimeoutMs` | `15000` | API 请求超时（毫秒） |
| `wecom.webhookUrl` | `https://qyapi.weixin.qq.com/...key=6ab0fb17-...` | 群机器人 Webhook |
| `wecom.secret` | `""` | Webhook HMAC-SHA256 签名密钥（可选，未配置则留空） |
| `wecom.mentionedMobileList` | `[]` | 消息 @ 的手机号列表 |
| `dedup.windowSeconds` | `0` | 同一 alertId 去重窗口（秒），`0` = 不去重，每条都推送 |
| `watcher.maxRetries` | `3` | API 调用最大重试次数 |
