## 4. 新增 SummaryClient API

```js
async getAverageValues(start, end, metrics, groups) {
    const params = {
      start, end,
      metrics: Array.isArray(metrics) ? metrics.join(',') : metrics,
      ...this._buildGroupParams(groups)
    };
    return this.request('averageValues', params);
}
```
