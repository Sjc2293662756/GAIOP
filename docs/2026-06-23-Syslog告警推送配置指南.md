# NAPM Syslog 告警推送 — 配置指南

> 最后更新：2026-06-23

## 1. 配置文件位置

远端服务器 `101.254.114.237`：

```
/home/netinside/.openclaw/workspace/skills/openclaw-napm-syslog-watcher/config/watcher.config.json
```

## 2. 完整配置项

```json
{
  "syslog": {
    "path": "/var/log/netinside/syslog.log"
  },
  "napm": {
    "host": "https://101.254.114.238/webservice/NetInside",
    "username": "GAIOP",
    "password": "GAIOP123",
    "tlsInsecure": true,
    "requestTimeoutMs": 15000
  },
  "wecom": {
    "webhookUrl": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key",
    "secret": "",
    "mentionedList": [],
    "mentionedMobileList": [],
    "routing": {}
  },
  "dedup": {
    "windowSeconds": 0,
    "maxCacheSize": 500
  },
  "watcher": {
    "maxRetries": 3,
    "retryDelayMs": 5000
  }
}
```

## 3. 配置项说明

### 3.1 syslog — 日志源

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `path` | string | `/var/log/netinside/syslog.log` | rsyslog 写入的 NAPM Syslog 日志文件路径 |

### 3.2 napm — NAPM API 连接

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `host` | string | `https://101.254.114.238/webservice/NetInside` | NAPM WebService 地址。支持多种写法：`https://IP/webservice/NetInside`、`IP`（纯 IP）、`https://IP` |
| `username` | string | `GAIOP` | NAPM 登录用户名 |
| `password` | string | `GAIOP123` | NAPM 登录密码 |
| `tlsInsecure` | boolean | `true` | NAPM 使用自签证书时设为 `true`，跳过证书验证 |
| `requestTimeoutMs` | number | `15000` | API 请求超时时间（毫秒） |

### 3.3 wecom — 企业微信推送

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `webhookUrl` | string | — | **必填**。企业微信群机器人的 Webhook 地址 |
| `secret` | string | `""` | Webhook HMAC-SHA256 签名密钥。如果添加机器人时未设置签名，留空即可 |
| `mentionedList` | string[] | `[]` | 要 @ 的用户 userid 列表，如 `["zhangsan", "lisi"]` |
| `mentionedMobileList` | string[] | `[]` | 要 @ 的手机号列表，如 `["13800138000"]` |
| `routing` | object | `{}` | 按告警级别路由到不同群（见 5.1） |

#### 获取 Webhook URL

1. 打开目标企业微信群 → 右上角 `···` → **群机器人** → **添加群机器人**
2. 复制 Webhook 地址，格式为：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
3. 粘贴到 `webhookUrl` 字段

### 3.4 dedup — 去重控制

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `windowSeconds` | number | `0` | 同一 alertId 的去重窗口（秒）。**`0` = 不去重，每条都推送**。设为 `300` 表示 5 分钟内同一告警只推送一次 |
| `maxCacheSize` | number | `500` | 去重缓存最大条数，超出后自动清理过期条目 |

### 3.5 watcher — 守护进程行为

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `maxRetries` | number | `3` | 调用 NAPM API 失败时的最大重试次数 |
| `retryDelayMs` | number | `5000` | 重试间隔（毫秒） |

## 4. 修改配置后如何生效

```bash
# SSH 到远端服务器
ssh netinside@101.254.114.237

# 编辑配置
```

看到 `去重: 已关闭`（或配置的窗口值）即表示新配置已加载。

## 5. 进阶用法

### 5.1 按告警级别路由到不同群

在 `routing` 中为不同严重级别指定不同的 Webhook URL：

```json
{
  "wecom": {
    "webhookUrl": "https://qyapi.weixin.qq.com/...key=默认群",
    "routing": {
      "紧急": {
        "webhookUrl": "https://qyapi.weixin.qq.com/...key=紧急告警群",
        "mentionedMobileList": ["13800138000"]
      },
      "重大": {
        "webhookUrl": "https://qyapi.weixin.qq.com/...key=重大告警群"
      }
    }
  }
}
```

- 紧急告警 → 单独推送到紧急告警群，并 @ 指定手机号
- 重大告警 → 推送到重大告警群
- 轻微告警 → 走默认 `webhookUrl`

### 5.2 恢复去重

如果告警太频繁，改为：

```json
{
  "dedup": {
    "windowSeconds": 300
  }
}
```

5 分钟内同一 alertId 只推送一次。

### 5.3 更换 NAPM 地址

```json
{
  "napm": {
    "host": "https://新IP/webservice/NetInside",
    "username": "新用户名",
    "password": "新密码"
  }
}
```

## 6. 服务管理

```bash
# 查看状态
sudo systemctl status napm-syslog-watcher

# 启动 / 停止 / 重启
sudo systemctl start napm-syslog-watcher
sudo systemctl stop napm-syslog-watcher
sudo systemctl restart napm-syslog-watcher

# 查看实时日志
sudo journalctl -u napm-syslog-watcher -f

# 查看最近 50 条日志
sudo journalctl -u napm-syslog-watcher -n 50 --no-pager

# 禁用/启用开机自启
sudo systemctl disable napm-syslog-watcher
sudo systemctl enable napm-syslog-watcher
```
