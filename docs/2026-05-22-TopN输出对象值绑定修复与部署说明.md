# 2026-05-22 TopN 输出对象值绑定修复与部署说明

## 背景

企业微信会话中出现过如下错误回答：

> “过去一小时、谁的连接失败数最多？”

系统实际已经构造并执行了 `resolvedQuery`：

- `service: topValues`
- `metric/topMetric: RFCI`
- `groups: IPAddress`
- `timeRange.key: last1hour`
- `constructedBy: openclaw_mainflow_resolver`

底层 NetInside API 也返回了完整的行级数据：

```text
group.argument = 192.0.2.39
metricValues[0].value = 43792
```

但最终回答把 `43792`、`1671` 等指标值当成了 IP 地址输出。

结论：问题不在 resolver，也不在 NAPM 查询执行，而在 TopN 查询结果的输出契约/展示层没有强制绑定“对象标签 + 指标值”。

## 修改目标

正确链路应保持：

```text
OpenClaw 构造 resolvedQuery
-> napm-skill-query 执行查询
-> skill 返回结构化 rows/data
-> OpenClaw 基于 rows/data 叙述
-> 企业微信插件只负责安全展示/发送
```

本次修改目标：

- TopN 结果必须保留 `object + rawValue/formattedValue` 绑定关系。
- 插件展示 TopN 时必须输出对象和值的表格。
- 不允许再把纯数值列表作为“可查指标示例”交给最终模型误读。
- 如果 TopN 结果缺少对象标签，直接提示不能生成“谁最多”的结论。

## 修改内容

### 1. Skill narration contract 增强

文件：

```text
skills/openclaw-napm-query/services/OpenClawNarrationContractService.js
```

新增能力：

- 从 `metricValues` 提取指标记录、指标标签、单位。
- TopN `narrationStructure.items` 增强为对象值绑定结构：

```js
{
  rank: 1,
  objectType: "IPAddress",
  object: "192.0.2.39",
  metric: "RFCI",
  metricLabel: "连接失败数(TCP服务器)",
  rawValue: 43792,
  formattedValue: "43792 files",
  unit: "files",
  groupPath: "v12.0.0:engine 0/0/napm/DB>clientIP 192.0.2.39"
}
```

- 为 TopN 生成表格型 `summary.displayText`：

```text
| 排名 | IPAddress | 连接失败数(TCP服务器) |
| --- | --- | --- |
| 1 | 192.0.2.39 | 43792 files |
```

### 2. 企业微信插件 TopN 展示防护

文件：

```text
napm-openclaw-plugin.remote.js
```

新增 `buildTopnUserFacingText()`：

- 仅处理 `narration.responseType === "topn"`。
- 优先读取 `narration.items[].object` 作为对象标签。
- 优先读取 `formattedValue/value/rawValue` 作为指标值。
- 输出 Markdown 表格。
- 如果对象标签缺失，返回：

```text
查询已返回 TopN 结果，但缺少对象标签，不能生成“谁最多”的结论。
```

并在 `buildUserFacingSkillText()` 中将 TopN 表格输出放到通用 fallback 之前。

这样不会再落入：

```text
可查指标示例：43792、1671、1577...
```

### 3. 回归测试

新增/修改测试：

```text
test/openclaw-narration-contract.test.js
test/napm-openclaw-plugin-topn-display.test.js
```

覆盖点：

- RFCI + IPAddress TopN 必须保留 IP 对象标签。
- TopN display text 必须包含 `IP + 指标值` 表格。
- 插件输出不得包含 `可查指标示例`。
- 插件输出不得出现 `IP 43792` 这类把指标值当对象的内容。
