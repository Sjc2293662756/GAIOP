## 统一自动时间粒度

- 将普通查询、巡检、综述和故障诊断的自动 `timeValues` 粒度统一到 `skills/shared/TimeGranularityPolicy.js`。
- 普通查询运行时会在时间戳分钟对齐后再按最终跨度补齐缺失粒度；巡检目录中的旧兼容实现也已同步，不再固定使用“1 天 = 1 小时”。
- 规则为：`t <= 6小时` 使用 1 分钟；`6小时 < t <= 3天` 使用 5 分钟；`3天 < t < 3,600,000秒` 使用 1 小时；`t >= 3,600,000秒` 使用 1 天。
- 原需求中的 30 天至约 41.67 天空档按 1 小时处理；合法显式请求粒度和 API 实际响应粒度的既有优先级保持不变。
- 移除巡检长窗口的报告侧周平均聚合。年度报告保留日粒度数据，`effectiveGranularity` 与 `actualGranularity` 一致；横轴仅隐藏重叠标签，不改变数据步长。
- 本次仅修改本地代码、测试和文档，未制作部署包、未连接或部署服务器。

- 指定自然月、自然季度和自然年使用 `Asia/Shanghai` 边界并对齐到分钟；当前时间段截止到当前分钟。
