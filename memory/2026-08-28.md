## 应用流量趋势 rc.33 复验与执行边界修复

- 真实验收再次复现“最近 7 天应用流量趋势如何？”错误落到 `TotalTraffic`，说明 rc.33 的 `before_tool_call` 语义守卫没有覆盖全部工具执行路径。
- 本地最小回路确认：直接调用 `napm-skill-query.execute` 时，旧实现会完成结构校验后调用 `RequirementParserService.executeGatewayRequest`；因此错误对象可以产生真实总流量结果。
- 修复 `napm-openclaw-plugin.remote.js`：在工具 `execute` 的南向调用前复用 `observePromptQuerySemanticMismatch`，应用趋势错配即返回边界失败；若缺少 trace-only `prompt`，回退读取 `resolvedQuery.userRequirement`。
- 新增 2 条直接执行回归测试，验证错误组合不会触达南向请求，并覆盖无 `prompt` 参数形态。
- 本地验证：101 个 Jest 套件、823 个测试通过；`npm run lint` 和 `npm run verify:runtime-contract` 通过。尚未重新发布或部署。
