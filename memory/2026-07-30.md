## 故障诊断降级保护

- 首次生产复测暴露：诊断第一步 HTTP 400 后，Agent 会降级拆成多次 Query 并猜测根因。
- 根因是插件误用 `registerHook` 注册 Agent Typed Hooks；当前 OpenClaw 必须使用 `api.on`，旧本地测试模拟接口与生产不一致。
- 已改为 `api.on` 注册，增加真实 API 契约测试，并通过 `after_tool_call` 将诊断失败绑定到当前 run/session。
- 诊断失败后禁止 Query、重复诊断和其他 Tool；`before_message_write` 与 `message_sending` 强制输出安全失败文本。
- 最终生产复测只调用 1 次 `napm-fault-diagnosis`，未降级调用 `napm-skill-query`；落盘文本明确禁止推断对象不存在、无数据或具体根因。
- 故障诊断 Skill 自身仍在 `step1_4xx_5xx_overview` 返回 HTTP 400，这是独立问题，后续单独整改。
